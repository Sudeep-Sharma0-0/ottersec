void ottersec::SecurityContext::clear ( )

securely wipes all cryptographic material from RAM.

bool ottersec::SecurityContext::set_keys ( const uint8_t *  master_key,

)

Securely stores the cryptographic keys required for SRTP encryption.

Validates the byte lengths against AES-128 requirements. If valid, copies the data into internal memory and marks the context as keyed. If invalid, the context is cleared and remains unkeyed.

Parameters
master_keyPointer to the 16-byte SRTP AES key.
key_lenLength of the master key (must be exactly 16).
master_saltPointer to the 14-byte SRTP salt.
salt_lenLength of the master salt (must be exactly 14).
Returns
true if the keys were successfully validated and stored.
false if the pointers are null or the lengths are incorrect.
