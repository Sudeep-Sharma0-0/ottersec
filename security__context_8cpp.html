Detailed Description

Manages the safe storage and lifecycle of cryptographic materials.

The SecurityContext class acts as a secure memory vault for the SRTP encryption keys generated during the TLS handshake. It ensures that sensitive AES-128 keys and salts are securely wiped from RAM using OpenSSL's memory cleanse routines before the object is destroyed.
