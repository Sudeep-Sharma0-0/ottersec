void ottersec::ControlServer::send_raw_payload ( const uint8_t *  data,
size_t  size 
)

Transmits a length-prefixed raw binary payload to the connected client.

Uses a standard network framing protocol: it first sends a 4-byte header (converted to network byte order via htonl) indicating the exact size of the payload, followed by the payload itself. Uses MSG_NOSIGNAL to prevent the application from crashing via SIGPIPE if the client disconnects.

Parameters
dataPointer to the serialized Protobuf byte array.
sizeThe total number of bytes in the payload.

◆ start()

bool ottersec::ControlServer::start ( )

Initializes the TCP socket, binds to the port, and starts the listener thread.

Enables SO_REUSEADDR to prevent "Address already in use" errors during rapid restarts. Spawns an asynchronous thread running accept_loop.

Returns
true if the socket successfully binds and the listener thread starts.
false if socket creation, binding, or listening fails.

◆ stop()

void ottersec::ControlServer::stop ( )

Safely shuts down the server.

Closes the active client connection, shuts down the main listening socket, and joins the accept_loop thread back to the main process to prevent segmentation faults.
