)

Starts the encrypted UDP video stream to the target client.

Dynamically constructs an x264 encoding pipeline. It enforces a strict 30-frame keyframe interval and forces timestamp generation to prevent dropping frames. Finally, it injects the 30-byte cryptographic material into the srtpenc plugin.

Parameters
dest_ipThe dynamically discovered IP address of the listening client.
dest_portThe UDP port to stream to (typically 5004).
srtp_keyA 16-byte cryptographic key generated during the TLS handshake.
srtp_saltA 14-byte cryptographic salt generated during the TLS handshake.
Returns
true if the pipeline was successfully constructed and set to PLAYING.
false if the pipeline is already running, or if element creation fails.
