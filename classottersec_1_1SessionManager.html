ottersec::SessionManager::SessionManager ( const OtterHandshakeConfig *  config)

Constructs a new SessionManager object.

Extracts the handshake port, certificate path, and private key path from the provided configuration. Falls back to default values (8443, "server.crt", "server.key") if the configuration is null or incomplete.

Parameters
configPointer to the user-defined handshake configuration.

◆ shutdown()

void ottersec::SessionManager::shutdown ( )

Halts the streaming session and cleans up all resources.

Transitions to TEARDOWN, stops the TLS server, wipes the cryptographic keys from memory, stops the GStreamer pipeline, and resets to IDLE.

◆ trigger_fall_event()

bool ottersec::SessionManager::trigger_fall_event ( const OtterFallEvent *  event)

Initiates the secure connection process upon detecting a fall.

Transitions the system from IDLE to HANDSHAKING. Spins up the TLS HandshakeServer and binds an asynchronous callback to handle the generated cryptographic keys once the client successfully authenticates.

Parameters
eventPointer to the fall event metadata.
Returns
true if the handshake process was successfully started.
false if the system is not in the IDLE state (e.g., already streaming).
